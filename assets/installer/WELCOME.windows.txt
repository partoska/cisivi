Cisivi (cisivi)

This installer will place the cisivi command-line tool and the libcisivi
library with its headers on your Windows system, and can add cisivi to
your PATH, so that it is available in Command Prompt and PowerShell.

Cisivi is a small, minimal CSV library and query tool. The cisivi
command reads CSV files and prints the columns, rows and values asked
for, filtered and sorted, as CSV, JSON or an aligned table, so that shell
scripts and pipelines can read and edit tables safely, quoted commas and
line breaks included. The library, libcisivi, reads and writes the same
CSV text from C.

After installation, run "cisivi -h" in a terminal to get started.
