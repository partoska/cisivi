# @partoska/cisivi-linux-arm64

This is the **Linux arm64** native binary for
[`@partoska/cisivi`](https://www.npmjs.com/package/@partoska/cisivi).

You should not install this package directly. Install the main package instead,
and npm will automatically pull in the correct binary for your platform:

```bash
npm install -g @partoska/cisivi
```

See the [`@partoska/cisivi` README](https://www.npmjs.com/package/@partoska/cisivi)
for documentation and usage.
